# 校园智能服务小助手
本项目是基于 Spring AI Alibaba 的智能校园服务对话系统

## 功能特性
- AI 对话：阿里百炼大模型，流式输出
- 校园知识库：RAG 检索增强，精准回答
- Multi-Agent：课表查询/导航/办事咨询
- 评估面板：AI 回答质量可视化
- Docker 部署：一条命令启动

## 技术栈
Java 17+ | SpringBoot 3.3.x | Spring AI Alibaba | MySQL 8.0 | Docker | Vue 3 | Python 3.0 以上

## 快速开始
前置条件：Docker Desktop + 阿里云百炼 API Key
1. 复制 .env.example 为 .env，填入 API Key
2. 双击 start.bat（或终端执行 docker-compose up）
3. 浏览器访问 http://localhost:8080
